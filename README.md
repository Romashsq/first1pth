# Часть 1. Теоретический блок (анализ и сравнение)
1.
Компилятор считывает исходный код программы и потом создает оптимизированный машинный код
А
Интерпретатор анализирует и потом выполняет команда за командой

Главные отличия: компилятор переводит код в машинный код, когда интерпретатор читатет код и выполняет строка за строкой

2.
При статической типизации тип закреплён за переменной и известен до запуска программы, его проверяет компилятор, и положить в переменную значение другого типа нельзя

когда при динамической типизации тип принадлежит значению, а не переменной, и определяется во время выполнения
