## 1. Что такое циклический алгоритм?

Это когда одно и то же действие повторяется много раз, чтобы не писать одно и то же миллион раз.

**Примеры задач:**

- Перебрать все товары в корзине и посчитать общую стоимость.
- Дать пользователю три попытки ввести пароль (`while attempts < 3`).
- Вывести «Hello world» пять раз через `range(5)`.

```python
total = 0
for product in products:
    total += product["price"]
```

## 2. Свойства алгоритма

Конечность, определённость, дискретность, результативность, массовость.

- **Конечность** нужна, чтобы цикл не крутился вечно.
- **Определённость** нужна, чтобы было чётко понятно, сколько раз повторять. Например, взять только первых 50 пользователей, а не прогонять миллион и грузить базу данных.

## 3. Чем отличаются `for` и `while`?

- `for` перебирает готовый набор, например `for product in products`.
- `while` повторяет, пока условие верно, и сколько раз это будет, заранее неизвестно.

```python
for i in range(3):          # ровно 3 раза
    print(i)

attempts = 0
while attempts < 3:         # пока условие верно
    attempts += 1
```

## 4. Что возвращает `range()`?

Последовательность чисел. Правая граница **не включается**.

| Вызов | Результат | Пояснение |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | старт с нуля |
| `range(2, 8)` | 2, 3, 4, 5, 6, 7 | от 2 до 8, без 8 |
| `range(2, 10, 2)` | 2, 4, 6, 8 | шаг 2 |
| `range(10, 2, -2)` | 10, 8, 6, 4 | обратный отсчёт, без 2 |

## 5. Что будет, если шаг у `range()` равен нулю?

Ошибка `ValueError`. С нулевым шагом цикл стоял бы на месте и никогда не дошёл до конца.

```python
range(1, 10, 0)  # ValueError
```

## 6. Что такое бесконечный цикл?

Цикл, который никогда не заканчивается.

**Примеры ошибок:**

- `while True` с `print` внутри и без `break`.
- В `while` забыли увеличить счётчик.

```python
while True:
    print("Hello")   # нет break — крутится вечно
```

## 7. Чем отличаются `break` и `continue`?

- `break` полностью останавливает цикл.
- `continue` пропускает текущий шаг и идёт дальше по циклу.

```python
for n in range(1, 8):
    if n % 2 == 0:
        continue     # чётные пропускаем
    print(n)         # 1 3 5 7
```

## 8. Как работает `else` у цикла?

Срабатывает, если цикл дошёл до конца **сам, без `break`**.

Это **не то же самое**, что `else` после `if`. Читается как «если break не было».

```python
for n in [1, 3, 5]:
    if n % 2 == 0:
        print("Нашёл чётное")
        break
else:
    print("Чётных нет")   # break не сработал
```

## 9. Что изменится, если цикл прервётся через `break`?

Блок `else` пропускается. Заканчивается только цикл, а код после него выполняется дальше.

## 10. Цикл завершился естественно, но тело не выполнилось ни разу

`else` всё равно срабатывает, потому что `break` не было. Например, цикл по пустому списку.

```python
for item in []:
    print("Тело цикла")
else:
    print("Цикл завершено")   # выполнится
```

## 11. Что такое вложенный цикл?

Цикл внутри цикла. Как столы и гости: обходишь каждый стол, и за каждым столом каждого гостя.

На каждый шаг внешнего цикла внутренний проходит **целиком**. Количество выполнений **перемножается**: 4 стола по 5 гостей дают 20.

```python
for table in tables:
    for guest in table["guests"]:
        print(guest)
```

## 12. Почему кривой счётчик в `while` даёт бесконечный цикл?

Python просто каждый раз проверяет условие. Если забыл `x += 1` или написал `x -= 1`, счётчик не движется к выходу, условие всегда верно, и цикл крутится вечно.

```python
x = 0
while x < 5:
    print(x)
    x -= 1   # x уходит в минус, x < 5 всегда верно
```

**Правило:** счётчик должен двигаться в сторону выхода.
